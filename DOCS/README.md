# DOCS

Game-specific documentation for the project being built on the Clouds framework — design, QA, and art context that isn't derivable from code, and isn't framework/coding guidance (that stays in the root `CLAUDE.md`).

This file is the index. As documents are added, list them here with a one-line pointer to what each covers and who owns it, so an agent reads only this index plus the one file actually relevant to the question — never the whole tree.

| Folder/File | Owner | Covers |
|---|---|---|
| [GD/](GD/README.md) | GD | Game design intent, feature specs, systems, balancing |
| [DEV/](DEV/README.md) | DEV | Technical specs/decisions beyond root `CLAUDE.md` |
| [QA/](QA/README.md) | QA | Test plans, acceptance criteria, bug conventions |
| [Art/](Art/README.md) | Art | Style guides, asset naming/import conventions |

Each subfolder keeps its own `README.md` index of the files inside it. Read the top-level index (this file) to find the right subfolder, then that subfolder's index to find the right file — don't read subfolder contents you weren't routed to.
